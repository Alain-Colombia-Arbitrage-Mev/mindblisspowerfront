# Montserrat (self-hosted)

Original Google Fonts v31 variable WOFF2 subsets, normal style, weights 300–900.
The primary font remains Montserrat. Latin includes Spanish accents and ñ;
extended Latin is loaded on demand through CSS unicode ranges.

Source stylesheet (modern browser):
https://fonts.googleapis.com/css2?family=Montserrat:wght@300..900&display=swap

Original assets (unmodified):
- Latin: https://fonts.gstatic.com/s/montserrat/v31/JTUSjIg1_i6t8kCHKm459Wlhyw.woff2
- Latin extended: https://fonts.gstatic.com/s/montserrat/v31/JTUSjIg1_i6t8kCHKm459Wdhyzbi.woff2
